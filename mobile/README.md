# MISEVO Mobile
MVP offline para Android/iOS com Expo + React Native + SQLite.

## MVP 1
- Banco SQLite local
- Dashboard
- Cadastro/listagem básica de insumos
- Cadastro/listagem básica de fichas
- Sem servidor e sem mensalidade de infraestrutura

Próximas etapas: edição completa de insumos, ingredientes por ficha, cálculo de CMV, preparações, categorias, estoque, backup/exportação e build Android.
